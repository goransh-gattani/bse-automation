BSE Announcements

Look up filings for a list of scrip codes, then view or download their PDFs. It runs inside a bseindia.com tab in your own browser, so BSE sees an ordinary visit and no server or proxy is needed. Set it up once:

Option A: bookmark button

  1. Show your bookmarks bar (Chrome: ⌘ShiftB, Windows: CtrlShiftB).
  2. Drag this button onto the bar: BSE Announcements
  3. Open bseindia.com and click the bookmark. A panel with the parameters and results table opens on top of the page.

Option B: paste into the console

  1. Open bseindia.com.
  2. Open DevTools (⌘OptionJ on Mac, CtrlShiftJ on Windows) and go to the Console tab.
  3. then paste it into the console and press Enter. Chrome may ask you to type allow pasting first.

Advanced: the proxy version of the page needs proxy/local_proxy.py running on your computer, or a Cloudflare Worker (see the README).
