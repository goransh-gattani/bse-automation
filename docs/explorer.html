BSE Explorer

Type a scrip code (or a name, symbol or ISIN) and see what BSE shows for it: price, ratios, market depth, trading stats, peers, announcements, an intraday chart and quarterly P&L. An API console runs any of the BSE endpoints by hand, and a search tab lists securities by segment, status and group. It runs inside a bseindia.com tab in your own browser, so BSE sees an ordinary visit and no server, proxy or Postman is needed. Set it up once:

Option A: bookmark button

  1. Show your bookmarks bar (Chrome: ⌘ShiftB, Windows: CtrlShiftB).
  2. Drag this button onto the bar: BSE Explorer
  3. Open bseindia.com and click the bookmark. The explorer opens on top of the page.

Option B: paste into the console

  1. Open bseindia.com.
  2. Open DevTools (⌘OptionJ on Mac, CtrlShiftJ on Windows) and go to the Console tab.
  3. then paste it into the console and press Enter. Chrome may ask you to type allow pasting first.

Running on localhost? The explorer itself is the front page (start python3 proxy/local_proxy.py first; a plain static server cannot reach BSE).

After an update, drag the button again to replace your old bookmark. The code is large; if your browser refuses to save the bookmark, use Option B.
